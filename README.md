# Support Active System

Система управления IT-заявками, картриджами, лицензиями и оборудованием кабинетов для отдела технической поддержки.

**Версия:** 2.6 (refactored)
**Стек:** Flask 3 + SQLite + vanilla JS + Bootstrap 5

---

## 📋 Возможности

### Заявки
- Полный цикл: создание → взятие в работу → выполнение → закрытие
- Каскадные фильтры (тип, кабинет, статус, приоритет, срок)
- Уведомления (админам, исполнителю, создателю)
- Комментарии с **@mentions** и автокомплитом
- Вложения (drag-n-drop, до 10 МБ)
- История изменений каждой заявки
- Проверка занятости исполнителя

### Оборудование кабинетов
- Сетевое оборудование (свитч, роутер, точка доступа…)
- Компьютеры с полной спецификацией (CPU, MB, RAM, диски, ПО)
- Принтеры (**сетевые** и **USB** к ПК)
- Документы ПО (сертификаты, лицензии)
- **Автопинг ПК** каждые 5 минут + ручной запуск
- **Drag-n-drop** для сортировки устройств
- Печать карточки кабинета

### Прочее
- Учёт картриджей с историей замен
- Лицензии ПО по кабинетам
- Внешние контакты (поставщики, сервис, партнёры)
- Справочник кабинетов и типов проблем
- Журнал аудита действий
- Экспорт заявок в XLSX
- PWA с push-уведомлениями (VAPID)
- Тёмная тема, горячие клавиши, командная палитра

### Безопасность
- PBKDF2-хеши паролей
- Rate limiting (Flask-Limiter)
- Блокировка после N неудачных попыток входа
- CSRF-защита
- CSP + X-Frame-Options + X-Content-Type-Options
- Мягкое удаление (soft delete)
- Журнал аудита с санитацией
